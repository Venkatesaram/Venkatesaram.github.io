2. Inline Style Override (Score 1000)

Inline Override

Inline styles (Score 1000) override external stylesheet ID, class, and element rules directly from the HTML markup.

3. Source Order Rule (Last Rule Wins)

Conflict Box

Both competing classes have identical specificity scores (10). The browser resolves this conflict by applying the rule written last in the CSS sheet cascade order (red overrides blue).

4. The !important Nuclear Option

!important Box

Even though an inline style defines the background as yellow, the !important flag on the stylesheet's background rule overrides it completely.

5. CSS Inheritance

I am the Parent Card

I am the Child Paragraph

Inherited properties like color cascade down to child nodes automatically. Non-inherited properties like border do not pass down and must be defined manually.

6. Cascade Layers (@layer)

Layer Target Box

Demonstrates modern CSS Layers: @layer base, theme, custom;. The custom layer override wins even though all classes have equal selector specificity.
