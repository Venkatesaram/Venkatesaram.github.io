CSS Functions Playground

1. calc()

calc(100% - 80px)

Dynamically subtracts 80px from the 100% parent container width.

2. min()

min(400px, 100%)

Selects whichever value is smaller: 400px or 100% of the parent width.

3. max()

max(300px, 50%)

Selects whichever value is larger: 300px or 50% of the parent width.

4. clamp()

Responsive Heading

Restricts text sizes between 20px (minimum) and 50px (maximum), using 5vw preferred scaling.

5. var()

Fetches variable tokens defined inside :root.

6. rgb()

RGB Colors

Creates standard solid colors using Red, Green, Blue integer indices.

7. rgba()

RGBA Colors

Extends rgb() by adding an alpha channel (opacity) from 0 to 1.

8. hsl()

HSL Colors

Generates colors via Hue angle (0-360), Saturation (%), and Lightness (%).

9. url()

Background Image

Loads external resources like images, svgs, or custom font-face files.
