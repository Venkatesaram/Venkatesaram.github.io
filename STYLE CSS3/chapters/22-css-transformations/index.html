Chapter 22: CSS Transformations

1. rotate()

rotate(45deg)

Rotate an element clockwise or counter-clockwise by specific degrees.

2. scale()

scale(1.2)

Increase or decrease the sizing factor of an element.

3. translateX()

translateX(80px)

Moves the element horizontally along the X-axis.

4. translateY()

translateY(-40px)

Moves the element vertically along the Y-axis.

5. translate()

translate(60px, -20px)

Moves the element simultaneously along both the X and Y axes.

6. skewX()

skewX(20deg)

Slants an element horizontally along the X-axis.

7. skewY()

skewY(20deg)

Slants an element vertically along the Y-axis.

8. skew()

skew(20deg, 10deg)

Slants the element along both the X and Y axes.

9. rotateX() (3D)

rotateX(180deg)

Rotates the element around the horizontal X-axis in 3D space.

10. rotateY() (3D)

rotateY(180deg)

Rotates the element around the vertical Y-axis in 3D space.

11. rotateZ() (3D)

rotateZ(180deg)

Rotates the element around the Z-axis in 3D space.
